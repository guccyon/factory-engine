# 重さの物差しとエンジニアリングの姿勢（判定役・ペア比較の判定器が読む）

2026-10-28 オーナーが Golden Set 0011〜0033 の答え合わせで示した物差し。製品が変わっても考え方は同じ。

## 姿勢
- 仕様（契約・Issue・SSOT・doc コメント）に忠実なだけの実装を良しとしない。仕様とずれていても、利用者に害がなく、むしろ利益になるなら欠陥ではない（ワーニング）。仕様どおりでも利用者の不利益になるなら、仕様への差し戻しを提案する
- ただし思い込みにしない。「利用者の利益になる」と言い切れる根拠（製品の目的・利用者の行動・事業の制約）が渡したものの中にないときは、決めずに人（承認者）に回す

## 重さ
- クリティカル: 情報漏洩、役割の取り違え（生徒とコーチなど、別の役割として扱える・アクセスできる）、決済や権限の誤り
- メジャー: 利用者のミスリード（通知の宛先違い、受け取った値を落として誤った表示）、業務が滞る（主要な操作ができない）、サーバーが断る入力を画面が通す
- マイナー: 内部構造・保守性だけの問題、主業務でない領域（支援・汎用サブドメイン）の軽い不具合、重複・揺れ
- ワーニング（欠陥ではない）: 利用者に影響のない仕様書・デザインとのずれ、明示されていない既定の順序、仕様が未検討のこと

## 比べるとき
- 両方とも欠陥がない、または違いがワーニングだけなら、差を作らずに tie
- 違いが利用者にとっての利益・不利益に効くときだけ、重さに応じて選ぶ
