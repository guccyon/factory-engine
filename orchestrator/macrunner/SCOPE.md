# Mac ランナーの範囲の宣言

Mac ランナーは、工場が利用者の Mac に置く常駐プロセスです。この文書は、ランナーができることと、しないことの全部です。ここにないことはできません。範囲を広げるときは、この文書と道具を同じ変更で直し、オーナーの承認を通します。

## できること

| まとまり | できること | 限り |
|---|---|---|
| シミュレーター | iOS シミュレーターの一覧・起動（画面は出さない）・停止・初期化 | Xcode に入っているシミュレーターだけ。実機には触らない |
| ビルド | 許したアプリを、シミュレーター向けの debug でビルドする | 許したリポジトリの、既定ブランチに入った（検査を通ってマージされた）コミットだけ。署名しない |
| アプリ | ビルドしたアプリを入れる・起動する・止める・プッシュ通知を送る | 許したアプリだけ。端末の標準のアプリやほかのアプリには触らない |
| 確かめる | 画面の撮影、画面の要素（アクセシビリティの木）の読み取り、タップ・スワイプ・文字入力・キー | シミュレーターの画面の中だけ |
| URL | シミュレーターで URL を開く | 許したホストの http(s)（触れる環境）と、許したアプリのスキームだけ |
| ログ | 許したアプリのプロセスのログを読む | 直近 10 分まで。OS の部品のログとほかのプロセスは読まない |
| 審査前の配布 | 許したアプリを release でビルドし、Mac の鍵で署名して、審査前の配布先（今は Firebase App Distribution の Android だけ）に上げる（ADR 0047） | マージ済みのコミットだけ。**Mac の画面で人が「配布する」を押したときだけ**（押されなければ 5 分で何もせずにやめる）。人が Mac で署名の鍵を入れ、宛先（工場か Mac の設定）があるまで閉じている。宛先は確かめの窓に出す。鍵のパスワードは Mac のキーチェーンから読んで署名の道具にだけ渡し、工場には返さない。配布先へは Mac の持ち主のログインで上げる |

## しないこと

- 人が Mac の前で押していない配布、署名の鍵・パスワード・配布先のログインを工場に渡すこと
- ストアへの提出・公開（審査に出す配布）。TestFlight は Gen2（ADR 0047）
- 実機の操作
- 道具として、シミュレーターの外の Mac のファイル・アプリ・設定を操作すること（ランナーの置き場とログの書き込みを除く）
- 任意のコマンド・シェルの実行
- マージ前のコードのビルド
- 持ち主の git の設定（`~/.gitconfig`・システムの設定）を読むこと（子プロセスには `GIT_CONFIG_GLOBAL=/dev/null`・`GIT_CONFIG_NOSYSTEM=1` を渡す。0.3.1）

## まだ残っている広さ（顧客に渡す前に閉じる）

- **ビルドは製品のコードを Mac の上で動かす**: Xcode のスクリプトや依存パッケージのフックは、ランナーを動かす利用者の権限で動き、隔離はない。今の歯止めは「許したリポジトリの、マージ済みのコミットだけ」。閉じる案: ビルドを専用の macOS 利用者で動かす
- **端末は Mac の全部のシミュレーターが対象**: 人が開発で使っているシミュレーターも初期化できる。閉じる案: 工場専用の端末の置き場（`simctl --set`）に限る
- **ペアリングの鍵は全部の道具に効く**: 鍵は窓口（工場）と Mac にだけあり、ジョブのワーカーには渡さない（ADR 0033）。ジョブごとに通す道具を絞るのは、工場の中継（one_orchestrator）で入れる

## 外と話す相手

- 工場: ランナーは待ち受けない。ペアリングした工場のランナーの窓口へ TLS で仕事を取りに行く（ペアリングのときに覚えた証明書の指紋の相手とだけ。呼び出しはランナーごとの鍵で署名する）。取りに行くときに機械の名前・版・置き場・端末の数・この範囲の要約を渡す
- 製品のリポジトリ（GitHub）と依存のパッケージ: ビルドのために取りに行く
- 審査前の配布先（Firebase App Distribution）: 人が押した配布のときだけ、Mac の持ち主の firebase login で上げる

## Mac に残るもの

| もの | 場所 | 外したとき |
|---|---|---|
| 常駐の設定 | `~/Library/LaunchAgents/local.factory.macrunner.plist` | 消える |
| ペアリングの鍵と窓口の指紋 | `~/.config/factory/macrunner.json`（0600） | 消える（工場の側の鍵も捨てる） |
| リポジトリの写しとビルドの作業場 | `~/Library/Application Support/factory-macrunner/` | 残る（消すのは人。ビルドは新しい 3 本だけ残す） |
| Android の署名の鍵（配布を開いたとき） | `~/.config/factory/android-upload.jks`（0600）と、パスワードはキーチェーンの `factory-macrunner-android-keystore` | 残る（鍵を捨てると、同じアプリの更新が配れなくなるので、消すのは人） |
| 呼ばれた操作の記録 | `~/Library/Logs/factory-macrunner/` | 残る（入力した文字と通知の中身は長さだけ） |

## 外し方

- 工場の操業コンソールの「登録済みのランナー」で「外す」を押す（1 分ほどで外れる）
- または、その Mac で `scripts/macrunner.sh uninstall`
