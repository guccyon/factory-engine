# ADR 0029: ラインの流量を宣言で決める

- 状態: 承認（2026-11-05 オーナー「上限の切り替えは工場側の機能として作ってほしい。Kubernetes の ReplicaSet みたいな考え方が筋が良さそう」）
- 関係: ADR 0009（操業コンソール）、ADR 0020（ラインの一時停止）、ADR 0024（知見と委員会。委員会の専用の枠）

## 文脈

アプリ側の開発が速く、トークンを使い切ってしまう。工場建設の検証のためには、ワーカー 1 機・ラインに同時に流すのは 1 件、のように絞れることが要る。今の数（ワーカーの数 `MAX_PARALLEL`、同時に流すチケットの数 `SUPERVISOR_MAX_INFLIGHT`、委員会の枠 `GOVERNANCE_PARALLEL`）は起動時の環境変数で、変えるたびにコンテナを作り直していた。

## 決定

1. あるべき数を制御プレーンに宣言し（events の `line.scaled`）、dispatcher と supervisor が周回ごとに読んで今の姿を合わせる。一度も宣言していなければ環境変数の値
   - `workers`: ラインのワーカーの数。委員会と知見の流れのジョブは数えない
   - `tickets`: ラインに同時に流すチケットの数
   - `governance`: 委員会と知見の流れのワーカーの数
2. 変える口は `factoryctl line scale --workers N --tickets N --governance N --reason ..`、操業コンソールの API `POST /api/line/scale`。変えた人・理由・時刻が残る。今の数は `factoryctl line` と、コンソールの状態（`factory.scale`）で見る
3. 数を下げても、動いているジョブは止めない（新しく取り出さないだけ）。0 にすると、その枠は取り出さない
4. ラインのワーカーは委員会と知見の流れのジョブを取らず、委員会の枠もラインのジョブを取らない（2 つの枠を独立させる）
5. ラインの一時停止（ADR 0020）は残す。宣言の数に関わらず、一時停止の間はラインの枠を取り出さない（`drain allow` で決めた PR を除く）

## 選ばなかった案

- 一時停止を `workers: 0` に置き換える: 更新の手順（drain → 更新 → resume）と番人の停止の記録が一時停止の events に乗っているので、今は分けたままにする
- 予算の枠（`BUDGET_WINDOWS_*`）も宣言に入れる: 予算は日報・停止の分類とつながっているので、次の作業で扱う（→ 下の追記で扱った）

## 追記（2026-11-08）: 使用量の予算も宣言にする

オーナー「使用量の予算も設定で変更できるようにしたい。予算のあてかたはもう少し柔軟にパターンを検討したいのだけど、とりあえず今は全体で 1 日あたりの予算を決めるか、曜日べつで決めるかできると良さそう」。

1. 予算を制御プレーンに宣言する（events の `budget.set`）。supervisor が周回ごとに読み、上げ直さずに次の周回から効く。一度も宣言していなければ今までどおり環境変数 `BUDGET_WINDOWS_WEEKDAY` / `BUDGET_WINDOWS_WEEKEND` の枠
   - `mode`: `daily`（毎日同じ額）か `weekday`（曜日ごとの額）
   - `daily_usd`、`weekday_usd`（`mon`〜`sun`）。決め方を切り替えても、もう一方の額は残す
2. 宣言の予算は 1 日（`BUDGET_DAY_START_HOUR`、7:00 JST から翌日の同じ時まで）を 1 つの枠にする。曜日は 1 日が始まった日の曜日。5 時間ごとの枠に分けたいときは、宣言を使わず環境変数の枠のまま
3. 予算に届いたときの止め方は変えない（新しい実装と衝突の解消を積まない。作業中のもの・検査・judge・p0 は止めない。`supervisor.budget_paused` と停止の分類 budget）
4. 変える口は操業コンソールの設定「使用量の予算」（`POST /api/budget`）と `factoryctl budget set`。変えた人・理由・時刻が残る。読み方は usage.py の 1 か所で、使用量のページの日ごとの予算の線も同じ宣言から引く（過去の日も今の宣言で引く。宣言の履歴を日ごとに当てるのは今後）
5. もっと柔軟な当て方（時間帯ごとの枠・製品ごと・週の上限から割り戻すなど）は、`mode` を足す形で後から広げる
