# ADR 0023: 学習の体系（8 テーマ・4 型・承認の線）と事例型の分析役

- 状態: 承認（2026-10-31 オーナー。決めどころ 5 点に回答）
- 関係: ADR 0013（Learn ループ）、ADR 0021（後片付け）、ADR 0019（内部品質の定期診断）、`definitions/learning_taxonomy.yaml`、`definitions/roadmap.yaml` の P3

## 文脈

ADR 0013 の Learn ループは、検査の指摘を束ねて検査ルールにする。2026-10-31 にオーナーから、学ぶのは検査の指摘より広い、という方向が示された。
学ぶ対象には、ドメインの理解、プロダクトの自律改善、開発プロセスの自律改善が含まれる。抽象化は何段かに分けて行い、なぜなぜで真因まで掘る。
そこで学習の対象を体系にした叩き台（学習の体系、2026-10-31）を作り、決めどころ 5 点をオーナーに出した。

## 決定（2026-10-31 オーナーの回答）

1. **テーマは 8 つで進める**: 外向き（1 利用者の体験、2 信頼性と性能、3 ドメインの理解）、内向き（4 役割間の言葉と伝達、5 成果物の品質、6 工程の進め方、7 判断の精度）、人（8 人の意図と好み）。
   学び方は 4 型（傾向型・事例型・反復型・校正型）。正本は `definitions/learning_taxonomy.yaml`。今の Learn ループはテーマ 5 × 反復型にあたる
2. **最初に回すのはテーマ 4 と 6**。材料（後片付けが保存したセッションログ、差し戻し、停止の記録）がすでにある。
   先に事例型（なぜなぜ）の分析役を作る。分析役はテーマ 3 と 5 にも流用する
3. **出荷後の信号（行動ログ・SLI・障害）は、合成の利用者を流して回路を先に作る**。詰まりや遅さをわざと仕込んだシナリオで、見つけて提案するまでを確かめる。完了条件は P5 に置く
4. **P3 の完了条件を体系に合わせて書き直す**。「最初に選んだテーマ（4・6）で、入力から作用先まで 1 周回り、効き目を測れた」。テーマ 5 の「ルールが採用され、教師信号が減った」も残す（`roadmap.yaml`）
5. **作用先ごとの承認の線は叩き台の表のとおり**。改善のチケット・検査ルール・既存の語への表記の統一・監視と手順書は工場が自動で行う。
   新しい用語や業務ルールの定義、役割への指示・ラインの設定・Engine、Blueprint は人が承認する（`learning_taxonomy.yaml` の approval）

## 事例型の分析役

- 1 件の出来事を、観点（仕様・伝達・検査・工程）ごとになぜなぜで掘り、真因と、テーマごとの学びの候補を返す。観点と上限は `learning_taxonomy.yaml` の case_review
- 対象は差し戻し（後片付けが会話の記録を保存した後）と、閉じた停止（60 分以上。予算と一時停止は除く）。1 日に積む数に上限を置く
- 分析役が読むのは、制御プレーンの記録と、後片付けのアーカイブからクレンジングしたセッションの抜粋。クレンジングでは、ツールの出力を落とし、秘密情報に見える文字列を伏せる
- 結果は記録（events の `case.analyzed`、artifacts の `CaseAnalysis`）だけに残す。作用先（用語集・指示・設定）には取り込まない。ワーカーのプロンプトにも入れない
- 学ぶ側に自分の効き目を採点させない（ADR 0013 の 8）。同じ真因の再発があったかは、測る側が記録から数える

## まだ決めていないこと（設計中）

2026-10-31 オーナー: 知見を都度足すだけだと、先の知見と後の知見が矛盾する。追加するときに、過去の知見の更新と形骸化の防止もセットで行える体制がほしい。
すべての知見を LLM の文脈として使うのではなく、蓋然性が高く繰り返す事象や、明確な線引きができるものは決定論で担保する。その判断をする committee と組にして運用し、振り返りなど学習ループのイベントの完了時に committee に持ち込む構造を作る。

- 知見の蓄積方法（置き場・形式・鮮度と正確性の維持・矛盾の解消・形骸化の防止）と committee は、別の検討で叩き台を作っている。決まるまで、事例型の分析の結果は記録だけに残す
- テーマ 4・6 の作用先への反映（用語の統一の PR、指示役の設定の提案）は、その決定の後に足す

## 選ばなかった案

- **最初にテーマ 1（利用者の体験）を回す**: 事業部らしさは一番出るが、合成の利用者を先に作る必要があり、1 周が遠い
- **テーマ 5 を仕上げてから広げる**: 学ぶ範囲が検査ルールに偏ったまま時間がたつ
- **P5 まで出荷後の信号を待つ**: 外向きのテーマの回路の確かめが遅れる
